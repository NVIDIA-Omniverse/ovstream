# Contributing

Thank you for your interest in ovstream.

## External contributions

This repository accepts **bug reports** via [GitHub Issues](https://github.com/NVIDIA-Omniverse/ovstream/issues) but **does not accept external pull requests** at this time. Pull requests opened against this repository will be closed without review.

Please file an issue if you encounter a bug or have a feature request. Be as specific as possible about the platform, ovstream version, and steps to reproduce.

## Reporting security vulnerabilities

**Do not report security issues via GitHub Issues.** Follow the process described in [`SECURITY.md`](SECURITY.md) — the [NVIDIA Product Security portal](https://www.nvidia.com/object/submit-security-vulnerability.html) is the only supported reporting channel.

## Asking questions

For general questions, discussion, and integration help, use the [NVIDIA Developer Forums](https://forums.developer.nvidia.com/c/omniverse/300). GitHub Issues should be reserved for bug reports.
